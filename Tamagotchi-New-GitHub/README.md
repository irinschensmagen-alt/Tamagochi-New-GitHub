# Tamagotchi — FINAL

Готовая финальная папка проекта для репозитория **Tamagochi-New-GitHub**.

## Что внутри
- `index.html` — запуск игры
- `style.css` — стили
- `script.js` — логика игры
- `assets/images/` — игровые изображения питомца и финальная робо-кормушка Fooddy
- `assets/designs/` — утверждённые дизайны экранов (яйцо, рождение, кормление, игра, лечение, финальный дашборд)
- `assets/templates/` — шаблоны RU / DE и общий обзорный шаблон

## В проекте
- 2 языка: **RU / DE**
- имя питомца вводит игрок, жёсткой привязки к имени нет
- этапы роста: **Baby → Kitten → Teen → Adult**
- 3 блока по 6 заданий: **Füttern / Spielen / Heilen**
- прогресс считается по всем выполненным заданиям
- современная робо-кормушка **Fooddy** с дозированной подачей корма
- в архив включены последние красивые утверждённые дизайны

## Как открыть
1. Открой папку `Tamagochi-New-GitHub`.
2. Запусти файл `index.html` в браузере.
3. Для GitHub Pages загрузи содержимое этой папки в корень репозитория.
