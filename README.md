# Tamagotchi Deutsch — расширенная тестовая версия

Добавлены серии заданий для проверки показателей.

## Покормить
6 раундов:
код Фудди → немецкое задание → 1 порция еды.

После каждой порции:
- голод -10
- настроение +2
- монеты +1
- опыт +5

## Поиграть
3 немецких задания.

После каждого правильного ответа:
- настроение +10
- энергия -10
- монеты +1
- опыт +5

## Лечить
3 немецких задания.

После каждого правильного ответа:
- здоровье +10
- настроение +3
- монеты +1
- опыт +5

После завершения блока здоровье устанавливается на 100.

Русские переводы немецких слов не показываются.
