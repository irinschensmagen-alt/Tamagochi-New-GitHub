# Tamagotchi — RU / DE

Финальная игровая сборка.

## Главное
- два полноценных режима: русский и немецкий;
- имя Тамагочи вводит игрок, фиксированного имени нет;
- в русском интерфейсе используются падежные формы имени;
- один код доступа к Fooddy, затем 6 заданий кормления подряд;
- после каждого правильного задания меняются показатели и общий прогресс;
- после завершения 6/6 меняется возрастной статус Тамагочи;
- после блока «Покормить» зелёным выделяется «Поиграть», затем «Лечить»;
- 18 сцен с персонажем: по 6 картинок для каждого блока;
- третий вариант ответа остаётся видимым;
- при хорошем финале Тамагочи мурлычет;
- при 50% и более ошибок или при досрочном выходе Тамагочи мяукает и засыпает в яйце;
- кнопка «Посмотреть на Тамагочи» / «Tamagotchi ansehen» открывает крупный план и включает мурлыканье.

## Изображения
- `assets/images/tasks/` — 18 изображений, привязанных к конкретным заданиям.
- `assets/images/character_gallery/` — сохранённые изображения персонажа с исходными русскими названиями.

## Запуск
Откройте `index.html` в браузере или разместите содержимое папки в корне GitHub Pages.
