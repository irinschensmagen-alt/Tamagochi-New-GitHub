# Tamagotchi — FINAL

Готовая рабочая папка проекта для репозитория **Tamagotchi-New-GitHub**.

## Состав
- `index.html` — интерфейс игры
- `style.css` — финальные стили
- `script.js` — игровая логика
- `assets/images/` — изображения питомца и Fooddy
- `assets/audio/` — довольное мурлыканье и жалобное мяуканье
- `assets/designs/` — утверждённые дизайны
- `assets/templates/` — шаблоны RU / DE

## Финальная механика
- два языка: RU / DE;
- имя вводит игрок, фиксированного имени нет;
- в русском интерфейсе используются падежные формы имени;
- 3 блока по 6 заданий: кормление, игра, лечение;
- общий прогресс меняется после каждого правильно выполненного задания;
- рост происходит только после полного блока 6/6;
- Fooddy: код доступа угадывается **только один раз** перед первым заданием кормления;
- после разблокировки выполняются задания 1–6 подряд, за каждое правильное задание выдаётся порция корма;
- варианты ответов, включая третий, доступны и не должны обрезаться;
- при хорошем финале взрослая кошка довольно мурлычет;
- при доле ошибок 50% и выше Тамагочи засыпает в яйце;
- при досрочном завершении Тамагочи жалобно мяукает и засыпает в яйце;
- есть кнопки «Играть» и «Завершить игру».
