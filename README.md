# Tamagotchi Deutsch — сбалансированная тестовая версия 6×6×6

Во всех трёх основных блоках теперь по 6 учебных заданий.

## 1. Покормить — 6 раундов
Каждый раунд:
1. разгадать код Фудди;
2. выполнить немецкое задание Essen und Trinken;
3. получить одну порцию.

После каждого успешного раунда:
- Голод: -10
- Настроение: +2
- Монеты: +1
- Опыт: +5

Стартовый голод 60 → после 6 порций 0.

## 2. Поиграть — 6 заданий
После каждого правильного ответа:
- Настроение: +5
- Энергия: -5
- Монеты: +1
- Опыт: +5

За весь блок:
- Настроение: +30
- Энергия: -30
- Монеты: +6
- Опыт: +30

## 3. Лечить — 6 заданий
После каждого правильного ответа:
- Здоровье: +5
- Настроение: +2
- Монеты: +1
- Опыт: +5

Стартовое здоровье 70 → после 6 заданий 100.

## Общий баланс
Если выполнить все 18 учебных заданий:
- Монеты: 18
- Опыт: 90
- Уровень: 4 (новый уровень каждые 30 опыта)

Показатели ограничены диапазоном 0–100.

Русские переводы немецких фраз не показываются.
