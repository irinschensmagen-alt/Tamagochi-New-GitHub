# Tamagotchi Deutsch — RU / DE

В игре добавлен полноценный переключатель языка.

## DE
- немецкий интерфейс;
- немецкие задания;
- немецкие реплики Анфисы и Fooddy.

## RU
- русский интерфейс;
- русские задания;
- русские реплики Анфисы и Fooddy.

Переключатель RU / DE доступен:
- на стартовом экране;
- в игровой шапке.

Текущее состояние игры при переключении языка не сбрасывается.

## v12 — имя выбирает игрок
- На старте поле имени пустое.
- Игра не запускается, пока ребёнок не введёт имя питомца.
- Выбранное имя автоматически используется во всех экранах, сообщениях и заданиях.

- В учебных заданиях вместо фиксированного имени используется `{name}`.
- Названия файлов изображений `anfisa_*.png` оставлены только как внутренние технические имена и игроку не показываются.
