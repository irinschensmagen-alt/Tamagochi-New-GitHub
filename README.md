# Tamagotchi Deutsch — версия «Один экран»

Главная цель этой версии: во время игры пользователь не прокручивает страницу.

После начала игры на одном экране одновременно видны:
- Анфиса и уровень;
- общий прогресс;
- все 6 показателей;
- три кнопки действий;
- текущее задание / Фудди / немецкий этап.

## Подсветка показателей
После каждого правильного ответа изменившиеся характеристики на короткое время подсвечиваются зелёным.

## Учебная структура
- Еда: 6 раундов «код Фудди → немецкое задание → порция».
- Игра: 6 немецких заданий.
- Лечение: 6 немецких заданий.

## Баланс
- Еда: голод -10, настроение +2, +1 монета, +5 опыта за успешный раунд.
- Игра: настроение +5, энергия -5, +1 монета, +5 опыта за задание.
- Лечение: здоровье +5, настроение +2, +1 монета, +5 опыта за задание.
