# Tamagotchi Deutsch — объединённая пробная версия

В проекте объединены:

- рождение Тамагочи;
- показатели питомца;
- кормление;
- игра;
- лечение;
- мини-игра «Робо-Кормушка Фудди».

## C# версия

Файлы:

- Program.cs
- TamagotchiDemo.csproj

Запуск:

dotnet run

## Веб-версия для GitHub Pages

Файлы:

- index.html
- style.css
- script.js

Загрузите эти три файла в корень репозитория GitHub.

Затем:

Settings → Pages → Deploy from a branch → main → /(root) → Save

## Что делает Фудди

Фудди загадывает число от 1 до 100.

Игрок получает подсказки:

- код больше;
- код меньше.

За каждый разгаданный код питомец получает одну порцию еды.

После шести кодов:

- голод становится 0;
- +10 настроения;
- +3 монеты;
- +15 опыта.

Некорректный ввод не считается попыткой.
