# Tamagotchi Deutsch — Живая Анфиса

Эта версия объединяет игру, рост и реакции Анфисы.

## Начало
1. `anfisa_egg.png` — космическое яйцо.
2. `anfisa_hatching.png` — рождение.
3. `anfisa_baby.png` — Анфиса появляется в игре.

## Рост
- Уровень 1 → `anfisa_baby.png`
- Уровень 2 → `anfisa_kitten.png`
- Уровень 3 → `anfisa_growing.png`
- Уровень 4 → `anfisa_adult.png`

Уровень повышается каждые 30 опыта.

## Реакции
- Еда → `anfisa_eating.png`
- Игра → `anfisa_playing.png`
- Болезнь → `anfisa_sick.png`
- Правильное лечение → `anfisa_healing.png`

После короткой реакции изображение возвращается к текущей стадии роста.

## Учебная структура
- Покормить: 6 циклов «код Фудди → немецкое задание → порция».
- Поиграть: 6 немецких заданий.
- Лечить: 6 немецких заданий.

## Баланс
Еда, каждый успешный цикл:
- голод -10
- настроение +2
- монеты +1
- опыт +5

Игра, каждый правильный ответ:
- настроение +5
- энергия -5
- монеты +1
- опыт +5

Лечение, каждый правильный ответ:
- здоровье +5
- настроение +2
- монеты +1
- опыт +5

Все характеристики ограничиваются диапазоном 0–100.
Изменившиеся показатели кратко подсвечиваются зелёным.

## Файлы изображений
Все изображения находятся в `assets/images/`.
Файл старого спящего котёнка `anfisa-baby.png` не используется.
