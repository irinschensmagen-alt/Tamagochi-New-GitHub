# Tamagotchi Deutsch — образовательная логика кормления

В этой версии Робо-Кормушка Фудди встроена внутрь действия «Покормить».

Цикл одной порции:

1. Фудди загадывает код от 1 до 100.
2. Игрок разгадывает код.
3. Открывается немецкое задание Essen und Trinken.
4. Только после правильного ответа Анфиса получает одну порцию.
5. Прогресс сытости увеличивается на 1 из 6.

После 6 порций блок «Еда» считается выполненным.

Русский перевод немецких фраз не показывается.
