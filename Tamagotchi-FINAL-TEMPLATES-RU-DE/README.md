# Tamagotchi — FINAL ALL IN ONE

Единая запускаемая версия игры.

## Запуск
Откройте `index.html` в браузере. Для публикации на GitHub Pages содержимое этой папки должно лежать в корне репозитория.

## В финальной версии
- интерфейс RU / DE;
- имя питомца задаёт игрок, фиксированного имени нет;
- волшебное яйцо и рождение питомца;
- 3 блока по 6 заданий: кормление, игра, лечение;
- общий прогресс: 18 заданий = 100%;
- рост только после завершения полного блока 6/6;
- стадии: Малыш → Котёнок → Подросток → Взрослый;
- современная робо-кормушка Fooddy с дозированной подачей;
- последняя утверждённая картинка Fooddy с симметричными руками и полноценными маленькими мизинцами;
- Fooddy показывается целиком и увеличивается по клику;
- неправильный ответ можно исправить, правильный обновляет показатели и прогресс.

## Утверждённые шаблоны интерфейса

В папке `assets/templates/` лежат визуальные шаблоны одного интерфейса:
- `game_template_de.png` — немецкая версия;
- `game_template_ru.png` — русская версия;
- `game_template_ru_de_overview.png` — общий лист RU + DE.

Шаблоны добавлены как визуальный эталон. Рабочая игра по-прежнему запускается через `index.html`.
